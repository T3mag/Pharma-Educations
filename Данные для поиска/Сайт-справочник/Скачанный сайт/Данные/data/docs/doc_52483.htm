Свойства

Каша для детоксикации организма овсяная со льном, яблоком и свеклой – специализированный пищевой продукт диетического профилактического питания для детоксикации организма. Богат веществами, важными для антиоксидантной защиты, поддержки работы печени и выведения токсинов: витамин С, овес, семена льна, свекла, яблоко. Продукт с высоким содержанием витамина С.

Действие

  • Защита от свободных радикалов и обеспечение процессов, которые препятствуют развитию патологий и способствуют оздоровлению организма.
  • Выведение токсинов (в т. ч. продуктов обмена) из организма.
  • Контроль массы тела.
  • Может применяться при диабете. Содержит всего 1.1 хлебных единиц в одной порции.

Эффективность и безопасность доказаны клинически.

Продукт входит в Комплексную программу питания ЛЕОВИТ DETOX.



Область применения

В качестве специализированного пищевого продукта диетического профилактического, в т.ч. диабетического, питания для детоксикации организма, в т.ч. для лиц, контролирующих массу тела:

  • после медикаментозной терапии;
  • при синдроме хронической усталости;
  • при избыточной массе тела.


Рекомендации по применению

Высыпать содержимое пакета в тарелку, добавить 140-160 мл кипящей воды, тщательно перемешать, накрыть крышкой, дать настояться 3-5 минут. Для получения желаемой консистенции можно изменить количество воды.

Перед применением рекомендуется проконсультироваться с врачом.

Использовать сразу после вскрытия пакета.
