Свойства

Суп-пюре со шпинатом и сельдереем – специализированный пищевой продукт диетического профилактического питания для детоксикации организма. Содержит компоненты для I и II фаз детоксикации организма и антиоксидантной защиты: шпинат, сельдерей, куркуму, лен, морковь, овес, петрушку, укроп, чеснок.

Действие

  • Защита клеток от токсинов.
  • Антиоксидантное действие.
  • Разгрузка органов пищеварения.
  • Снижение массы тела.

Эффективность и безопасность доказаны клинически.

Продукт входит в Комплексную программу питания ЛЕОВИТ DETOX.



Область применения

В качестве низкокалорийного специализированного пищевого продукта диетического профилактического питания для детоксикации организма, в т.ч. для лиц, контролирующих массу тела; при проживании в экологически неблагоприятных условиях; для снижения последствий вредных привычек; при избыточной массе тела.



Рекомендации по применению

Высыпать содержимое пакета в тарелку, добавить 180-200 мл кипящей воды, тщательно перемешать, дать настояться 3-5 минут. Для получения желаемой консистенции можно изменить количество воды.

Перед применением рекомендуется проконсультироваться с врачом.



Побочное действие
При применении в соответствии с рекомендациями - не сообщалось.
